
# To-Do List Tracker

This is a simple to-do list tracker application built using **React** and **TypeScript**, styled with **TailwindCSS**, and leveraging **React Query** for API interactions. The application provides a user-friendly interface for managing tasks effectively.

## Features

- **Create Task**: Add a new task through an input field with basic validation.
- **Toggle Task Completion**: Mark tasks as completed or incomplete with a checkbox.
- **Remove Task**: Delete tasks from the list.
- **Automatic Sorting**: Completed tasks automatically move to the bottom of the list.
- **Filter Tasks**: View tasks by status:
  - All
  - Completed
  - Incomplete

## Tech Stack

- **React + TypeScript**: For building the user interface and managing component states.
- **TailwindCSS**: For easy and responsive styling.
- **React Query**: For efficient data fetching and state management.
- **DummyJSON API**: Used as a placeholder for managing to-do tasks.

API Details
This project utilizes the DummyJSON API for fetching and managing to-do data. Ensure you have a stable internet connection while running the application to interact with the API.
